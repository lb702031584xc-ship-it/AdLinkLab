# P2-11：商品库同步评估（管理员授权 + 白名单 + 官方 API，默认关闭）

> 状态：评估 + 授权设计文档，**不写同步执行代码**。商品库同步默认关闭；
> 只有当下面“开通条件”全部满足时，才可由管理员批准开通。任何一项不满足 → 保持关闭。

## 开通条件（全部满足才可用）

1. **官方联盟 API 才可用**：只允许通过联盟官方 API 同步；禁止爬取、非授权抓取、非官方绕过手段。
2. **管理员审批**：按 §5 管理员授权机制（`docs/admin-grants.md`）申请 → 审批，绑定联盟 + 账号 + 白名单站点/域名 + 有效期。
3. **自有授权账号 + 证据**：必须使用自己名下的授权账号，并提供 §5.3 证据（账号归属证明、联盟授权截图/链接等），证据过期/伪造 → 自动吊销。
4. **上限**：每联盟每租户每日数量 + 频率上限；超限自动停 + 审计 + 管理员通知，重新申请才可恢复（不自动恢复）。
5. **自动停用**：联盟警告 / 限流 / 封号风险 / 出现非官方来源 → 自动停用，重新审批才可恢复。
6. **数据用途**：同步数据仅用于本租户 Offer 选择参考（如 P1-30 筛选预设）；禁止再分发、禁止全量镜像、禁止跨租户共享。
7. **同步日志可查**：每次同步记录何时 / 哪个联盟 / 哪个账号 / 数量 / 成功 / 失败，供审计。

## 不做（硬边界）

- 不做爬取、不做非官方 API、不做绕过联盟授权的任何手段。
- 不做跨租户共享商品库；不做公开商品库镜像。
- 同步本身未实现：本文件只是“如果未来要做，必须满足的条件”，不是实现承诺。

## 与 §5 授权机制的关系

- 授权申请、审批、白名单、上限、过期、吊销走 §5 的 `admin_grant_*` 表 + API（见 `docs/admin-grants.md`）。
- 商品库同步的 capability 名：`catalog-sync`；白名单值为联盟域名/站点域名列表（逐个确认，禁止通配符 / “全部网站”）。
